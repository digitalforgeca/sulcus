# Sulcus sample consumer

Run this sample while the Sulcus extension is installed (or in a development instance where both extensions are loaded).

- Command: `Sulcus Sample: Use API`
- What it does: activates the Sulcus extension, calls `summarizeSelection()` and shows the last summary.

Replace `your-publisher` in `package.json` with the publisher ID you use when publishing the Sulcus extension.
