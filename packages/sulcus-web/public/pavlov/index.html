Overview

What is Pavlov?

Pavlov is a zero-dependency gamification core that handles XP tracking, level progression, badge awards, and streak management. It’s designed to be embedded in any TypeScript/JavaScript app — React, Node.js, serverless, CLI tools. You define the rules; Pavlov handles the math.

Core Features

Everything you need. Nothing you don’t.

⚡
XP Engine

Define XP rules per action. Multipliers, caps, cooldowns. Pure functions, no side effects.

📈
Level System

Configurable level thresholds with names, tiers, and custom XP curves. Linear, exponential, or arbitrary.

🏅
Badge System

Declarative badge definitions with condition evaluators. Award badges on event counts, XP thresholds, or custom logic.

🔥
Streak Tracking

Daily/weekly streak counters with grace periods, multipliers, and freeze tokens.

Quick Start

Up and running in minutes.

engine.ts TypeScript 
import { createPavlov } from '@digitalforgestudios/pavlov';

const engine = createPavlov({
  levels: [
    { xp: 0,     name: 'Newcomer'   },
    { xp: 100,   name: 'Regular'    },
    { xp: 500,   name: 'Power User' },
    { xp: 2000,  name: 'Champion'   },
    { xp: 10000, name: 'Legend'     },
  ],
  xpRules: {
    'post.create':   10,
    'comment.add':    3,
    'login':           1,
    'invite.accept': 25,
  },
  badges: [
    { id: 'first_post',      name: 'First Post',      condition: { event: 'post.create', count: 1  } },
    { id: 'social_butterfly', name: 'Social Butterfly', condition: { event: 'comment.add',  count: 50 } },
    { id: 'streak_7',         name: 'On Fire',         condition: { type:  'streak',       days:  7 } },
  ],
});

// Award XP
const result = engine.award('user_123', 'post.create');
// → { xp: 10, totalXp: 210, level: 2, levelName: 'Regular', newBadges: [] }

// Check profile
const profile = engine.getProfile('user_123');
// → { totalXp: 210, level: 2, levelName: 'Regular', badges: ['first_post'], streak: 3 }
